# 打鍵道場

漢字と英単語のタイピングゲームです。HTML ファイル1つで動きます。

**遊ぶ:** https://lumiere2110.github.io/typing-dojo/

## 種目

- **漢字** — 表示された漢字の読みをローマ字で入力します。読みの表示とローマ字ガイドはオンオフできます。`shi`/`si`、`ja`/`zya`、`n`/`nn`、`kko`/`xtuko` など、よく使われる打ち方はどれでも正解になります。
- **英語（英単語の入力）** — 表示された英単語を入力します。日本語の意味の表示をオンオフできます。
- **英語（英単語の意味）** — 日本語の意味を見て英単語を入力します。頭文字と文字数のヒントをオンオフできます。

## レベル

| Lv | 漢字 | 英語 |
|----|------|------|
| 1 | 小学〜中学（図書館・宿題） | 中学（library・believe） |
| 2 | 中学〜高校基礎（矛盾・曖昧） | 高校基礎（environment） |
| 3 | 高校〜一般（葛藤・払拭） | 大学受験（phenomenon） |
| 4 | 教養・難読（齟齬・忖度） | 英検準1級（ubiquitous） |
| 5 | 超難読・熟字訓（魑魅魍魎） | 英検1級（ephemeral） |

各レベル15語から、5・10・15問を選んで出題します。

## リザルト画面

ランク、1分あたりの打鍵数、正確率を表示します。間違えた問題やスキップした問題ごとに、読み・意味・覚え方（英語は品詞と例文も）と、どこで何回ミスしたかを解説します。間違えた問題だけを復習することもできます。

## 操作

- `Enter` で開始、`Esc` で「わからない」（答えを表示して次へ）
- 日本語入力（IME）がオンのままでも、全角でも半角でも入力できます
- スマホではカードをタップするとキーボードが開きます

## ローカルで動かす

`index.html` をブラウザで開くだけです。ビルドは不要です。
